## Hello World

Welcome to my new blog powered by **VitePress** and deployed via **GitHub Actions**!

This is the very first post on this site. I am keeping the source code entirely isolated in its own Git history using Git worktrees.

### Why VitePress?

* **Fast:** Built on top of Vite and Vue.
* **Markdown Centric:** Write everything in plain text.
* **Powerful:** You can embed Vue components directly inside Markdown.
