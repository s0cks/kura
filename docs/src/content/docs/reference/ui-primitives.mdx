## Container Properties

Containers are <Node name="boxes" link="/kura/reference/nodes/box" /> that contain children

<PropertyTable inherits={"box"}>
  <Property name="gap" types={["Px", "Pct"]}>
    Spacing between adjacent children (`>= 0`).
  </Property>
  <Property name="direction" types={["Direction"]}>
    Main layout axis: `"row"`, `"column"`, `"row-reverse"`, or `"column-reverse"`.
  </Property>
  <Property name="align" types={["Align"]}>
    Cross-axis alignment of children: `"start"`, `"center"`, `"end"`, or `"stretch"`.
  </Property>
  <Property name="justify" types={["Justify"]}>
    Main-axis distribution: `"start"`, `"center"`, `"end"`, `"space-between"`, `"space-around"`, `"space-evenly"`.
  </Property>
  <Property name="wrap" types={["Bool"]}>
    Whether children wrap onto multiple lines when they overflow the main axis.
  </Property>
</PropertyTable>

## Text

A <Node name="box" /> for displaying text

<PropertyTable inherits={"box"} >
  <Property name="value" types={["String"]}>
    What to show.
  </Property>
  <Property name="size" types={["Px"]}>
    The font size, in `px` (`>= 0`).
  </Property>
  <Property name="font-family" types={["String"]}>
    The font: a name, or a comma-separated list in order of preference.
  </Property>
  <Property name="color" types={["Color"]}>
    The color of the text. Opaque black if it isn't given.
  </Property>
  <Property name="text-align" types={["String"]}>
    Horizontal text alignment: `"left"`, `"center"`, or `"right"`.
  </Property>
  <TableSeparator text="Positional Arguments"
                  color="primary" />
  <Property name="value"
            types={["String"]}>
    The text to render
  </Property>
</PropertyTable>

<Example>

```kura
#text(size: 24px,
      font-family: "Inter, sans-serif",
      color: white,
      "Hello World")
```

</Example>

<Aside>

`font-family` is a constant string, like `size`, because text is measured before the view runs.
The renderer finds the first family in the list that is installed on the system, and uses the system's
default font when none is. Text wraps at word boundaries to the room its box has, and is laid out and drawn
with the same measurements.

</Aside>

## Input

A single-line <Node name="box" /> for user input.

<PropertyTable inherits={"box"}>
  <Property name="size" types={["Px"]}>
    The font size, in `px` (`>= 0`).
  </Property>
  <Property name="font-family" types={["String"]}>
    The font: a name, or a comma-separated list in order of preference.
  </Property>
  <Property name="color" types={["Color"]}>
    The color of the input text.
  </Property>
  <Property name="text-align" types={["String"]}>
    Horizontal text alignment: `"left"`, `"center"`, or `"right"`.
  </Property>
  <Property name="on-input" types={["Message"]}>
    Message dispatched when the user edits the text.
  </Property>
  <TableSeparator text="Positional Properties" />
  <Property name="value" types={["String"]}>
    The current text value inside the input.
  </Property>
</PropertyTable>

<Example>

```kura
#input(size: 16px,
       padding: 8px,
       border-color: #444444,
       border-width: 1px,
       on-input: UpdateQuery,
       "Search....")
```
</Example>

<Aside>

Like `#text`, `font-family` and `size` are constants used to measure text metrics prior to layout.

</Aside>
