`#list` is a vertical <Node name="scroll" /> container whose `direction` defaults to `"column"` unless overridden.

<Example>

```kura
#list(height: 240px, gap: 6px) {
  for _, item in model.items =>
    #text(item.label)
}
```

</Example>

<PropertyTable inherits="container">
  <Property name="on-scroll" types={["Message"]}>
    Message dispatched when the scroll offset changes.
  </Property>
</PropertyTable>

## Notes

- Every row inside a `#list` is laid out and drawn regardless of whether it is currently within the visible scroll bounds.
- Shares all scroll offset retention and wheel bubbling behavior with <Node name="scroll" />.
