A <Node name="container" /> that responds to pointer clicks by dispatching its `on-click` message.

<Example>

```kura
#button(
  padding: 10px,
  fill: blue,
  radius: 6px,
  on-click: Submit,
) {
  #text(size: 14px, color: white, "Save")
}
```

</Example>
